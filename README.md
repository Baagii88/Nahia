## Ажиллуулах

Төслийн үндсэн хавтаснаас `python run_app.py` ажиллуулна. Компьютерын хаяг: http://localhost:8080/index.html. Launcher нэг Wi-Fi сүлжээн дэх утасны хаягийг мөн хэвлэнэ.

Зөвхөн компьютер дээр турших: `python -m http.server 8080 --bind 127.0.0.1`.

index.html-ийг шууд файл хэлбэрээр нээхэд дотоод өгөгдөл ашиглана. Service worker нь HTTPS эсвэл localhost орчинд ажиллана; энгийн LAN HTTP хаягаар утсанд оффлайн суулгалт баталгаажаагүй. HTTP болон file origin бүрийн ахиц тусдаа хадгалагдана.

## Бичих горим

Бичих дэлгэц дотроо HSK түвшин сонгох, ханз/пиньинь/утгаар үг хайх, жагсаалтаас сонгох болон Өмнөх/Дараагийн үгээр шилжих боломжтой. Үг солиход сонгосон горим хадгалагдана. Үгийн үндсэн жагсаалт шинэ HSK PDF-үүдийнх; хуучин монгол PDF нь зөвхөн утгын тулгах эх юм.

- Дагаж бичих: дараагийн зураасыг хөдөлгөөнөөр үзүүлнэ; Эхлэх дарж бичнэ.
- Бүдэг загвартай: бүдэг дүрсийг харан зөв дарааллаар бичнэ.
- Загваргүй: загвар болон алдааны дараах автомат hint-гүй цээжээр бичнэ.
- Чөлөөт бичилт: зөв буруу, дарааллыг шалгахгүйгээр дурын зураас зурна.

Олон ханзтай үгийн ханзыг тус бүр сонгоно. Үгийн дуудлагыг дан ханзын дуудлага мэт харуулахгүй. 3,088 ханзын зураас дотоод санд бий; бусад ханзыг чөлөөт горимд бичиж болно.

## Флашкарт

Хугацаа болсон картыг л үзүүлнэ. Дахин: 1 минут; шинэ картын Сайн: 3 хоног; Хялбар: 7 хоног. Дараагийн хугацаа ахицаас хамаарна. Энэ нь тус аппын хялбаршуулсан SRS, AnkiDroid-ийн scheduler-ийг шууд нэгтгээгүй.

Ахиц localStorage-д хадгалагдана. Ахиц нөөцлөх товчоор JSON татаж, Нөөцөөс нэгтгэх товчоор сэргээнэ. PDF шилжилтэд хуучин SRS ID-нууд alias эсвэл legacy картаар хадгалагдсан.

## Радикалын дэлгэрэнгүй 214 хичээл

**Хичээл → 214 радикал** дотроос эхлэх 30 радикал эсвэл бүх 214-ийг сонгоно. Хайлт нь эхлэх багц сонгосон байсан ч бүх 214-өөс хайна. Ахицтай дараалал, өмнөх/дараах хичээл, дасгал руу шууд очих товчтой.

Хичээл бүрд үндсэн хэлбэр, хувилбар, дуудлага, монгол/англи утга, өнгөөр ялгасан жишээ, байрлал, үгийн холбоос, сонсох/бичих/SRS холбоос, хоёр тайлбартай дасгал бий. Нийт 701 жишээ, 428 дасгал. Ховор радикалын жишээний тоо цөөн байж болно; хамааралгүй ханз нэмээгүй. Дэлгэцэд эхний дөрвөн жишээг гаргаж, үлдсэнийг нээж үзнэ. Өнгийг нууж өөрийгөө шалгаж болно.

Утгын холбоо, дуудлагын холбоо, дүрсний бүрэлдэхүүн, толь зүйн радикалыг тусад нь тэмдэглэсэн. 冫–氵, баруун–зүүн 阝, сар 月–мах ⺼, 口–囗, 土–士, 日–曰, 礻–衤 харьцуулалттай. Радикалын утгаар бүх ханзыг тайлбарлаагүй; түүхэн гарал үүслийн бүрэн курс биш.

Өнгө нь Make Me a Hanzi-ийн `decomposition` ба `matches` өгөгдлийн зураасны замаар тодорхойлогдоно. Төсөл дэх радикалын эх индексийн жишээг шууд хуулалгүй бүтцээр нь шалгасан. Нэмэлт хянасан AI тайлбар: `data/radical_example_reviews.json`; эхийн snapshot: `data/radical_dictionary.jsonl`; тулгалт: `data/radical_lessons_verification.json`. Хэрэглэгчийн өгсөн зургуудын лого, постерийг хуулж багцлаагүй.

Дахин үүсгэх: `python tools/build_learning_data.py`, дараа нь `python tools/build_radical_lessons.py --require-complete`. Хянасан утга эсвэл зураас дутвал хоёр дахь команд амжилтгүй дуусна. ## Үгийн холбоосын интерактив мод

**Хичээл → Үгийн мод**: 人、口、手、日、月、木、水 гэсэн долоон суурь ханз, нийт 21 салаа. Нэг салааг дарж дэлгээд суурь ханз → үг → холбоос ханз → бусад гурван үг гэсэн дөрвөн алхмаар үзнэ. Өөр салаа сонгоход өмнөх салаа хураагдана. Утасны дэлгэцэд төгсгөлийн картууд босоо байрлана.

人 мод нь 人们 → 们 → 我们/你们/他们, 男人 → 男 → 男生/男孩儿/男朋友, 女人 → 女 → 女生/女儿/女朋友 гэсэн бүтэцтэй. Энэ нь үг тогтоох холбоос; түүхэн гарал үүсэл, ханзны хувирал эсвэл HSK түвшний дараалал биш. 果 орсон 如果 нь “хэрэв” болох зэрэг утгыг механикаар тайлбарлаж болохгүй тохиолдлыг тэмдэглэв. Ханзын дан дуудлага болон үгэн доторх сул хөгийг ялгасан (头 tóu / 木头 mùtou).

Бүх зангилаа монгол/англи утга, pinyin, сонсох, бичих, SRS товчтой. Ханз ба дуудлага яг таарвал үндсэн HSK карт ашиглана. Таарахгүй хянасан сургалтын үгс `word_tree_…` тогтвортой ID-тай нэмэлт карт болж, SRS хадгалалт/нөөцлөлт/сэргээхэд хамрагдана. Эдгээр нь үндсэн HSK 11,000 үгийн жагсаалт болон түвшний тоог өөрчлөхгүй. Танихгүй дурын ID-тай картыг хэвийн байдлаар хассаар байна.

Долоон модны үгийн тайлбарыг Codex AI өөрөө хянан бэлдсэн; мэргэжлийн хүний баталгаатай орчуулга гэж тэмдэглээгүй. Өгөгдөл, модны бүтэц `js/word_trees.js`-д, хэв маяг `css/word_trees.css`-д бий. Шинэ файлууд service worker-ийн үндсэн оффлайн нөөцөд орно.

## Энэ ханз орсон өөр үгс

Үгийн сангийн нэг ханзтай картын доор гурван холбоотой үг, монгол утга, HSK түвшин, дэлгэрэнгүй болон модоор үзэх товч байна. Олон ханзтай үгт **Ханз тус бүрийн холбоотой үгс** хэсгийг дэлгээд ханз бүрийн товч жагсаалтыг харна. Бичих дэлгэцэд сонгосон ханзын холбоотой үгс нь бичих товчлууруудын доор шинэчлэгдэнэ.

Дэлгэрэнгүй native dialog нь ханз/pinyin/монгол/англи хайлт, HSK түвшний шүүлт, жагсаалт/модон харагдац, 12 үгээр нэмэгдүүлэх дэлгэлттэй. Үг бүр сонсох, бичих, үндсэн SRS-д нэмэх товчтой. Нэг бичлэгийн өөр дуудлага, утгыг арилгахгүй; ижил бичлэгийн бүртгэлүүд нэг үгийн дор тусдаа харагдана. Одоогийн бүтэн үгийг “өөр үгс”-ийн жагсаалтад давтаж үзүүлэхгүй. Бэлэн долоон модонд таарах ханзнаас дөрвөн алхамтай сургалтын мод руу орж болно.

Зөвхөн шинэ HSK-ийн локал 11,000 мөрөөс индекс үүсгэнэ. Энэ нь бүх хятад үгийн сангийн бүрэн толь биш. 2,879 ханз нийлмэл үгэнд орсон; тус бүрийн жагсаалтыг хадгалсан эхээс олно. Үг байхгүй үед зохиож нэмэхгүй. Эхлэх зөвлөмж нь сонгосон түвшин хүртэлх үгийг урьтал болгож, хүрэлцэхгүй бол дараагийн ойр түвшнийг сонгоно; үг бүр бодит түвшний шошготой.

Үйлдлийн зарчим нь HanziStroke-ийн “Words Sharing Characters” хэсэгтэй төстэй: https://www.hanzistroke.com/word/你好 . Тус сайтын бүх үг, тайлбарыг хуулалгүй өөрийн шинэ HSK үгийн сан, монгол тайлбар, SRS болон бичих хэсэгтэй холбосон.

Логоны 木 нь **mù**, “мод” гэсэн утгатай. Нахиа нэрийг өсөлт, өдөр бүр бага багаар сурахтай холбосон. Нүүрний 学 (xué) нь “сурах”.

Энэ нийтэлсэн багцад өгөгдөл дахин үүсгэх түүхэн Python хэрэгслүүдийг оруулаагүй; ажиллах өгөгдөл, хяналтын бүртгэл ба бие даасан тестүүдийг оруулсан. README дахь `tools/` жишээнүүд нь анхны хөгжүүлэлтийн workspace-д хамаарна.
